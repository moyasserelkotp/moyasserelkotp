```text

                    │    User Query   │
                    └────────┬────────┘
                             │
                             ▼
                    ┌─────────────────┐
                    │ Query Processing│
                    └────────┬────────┘
                             │
                             ▼
              ┌──────────────────────────┐
              │      Vector Search       │
              │ Qdrant • FAISS • Chroma  │
              └────────────┬─────────────┘
                           │
                           ▼
              ┌──────────────────────────┐
              │       Reranking          │
              │ Context Selection        │
              └────────────┬─────────────┘
                           │

              └────────────┬─────────────┘

                           ▼
                    ┌──────────────┐
                    │ Final Answer │
                    └──────────────┘
```
